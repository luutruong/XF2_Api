# Truonglv/Api

Mobile-app API layer for XenForo: adds `tapi-*` endpoints (app bootstrap, auth, push subscriptions, in-app purchases, notifications, bookmarks, featured contents, search, batch requests) and extends the existing XenForo API endpoints with extra parameters and actions.

**API reference: [API.md](API.md)**

For the base XenForo endpoints this add-on builds on, see the [official XenForo API docs](https://xenforo.com/community/pages/api-endpoints/).
